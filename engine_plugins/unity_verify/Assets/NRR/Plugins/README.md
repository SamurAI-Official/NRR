# NRR Native Plugin (Unity)

Unity locates the NRR native library via the `"nrr"` DllImport name in the
managed bindings (`NRRNative.cs`). Place the correct binary for each target
platform under this `Runtime/Plugins/` tree.

## Layout

```
Runtime/Plugins/
├── Windows/x86_64/nrr.dll      # Windows x64
├── Linux/x86_64/libnrr.so      # Linux x64
├── macOS/universal/libnrr.dylib# macOS universal
└── Android/arm64-v8a/libnrr.so # Android arm64
```

## Building the library

The NRR native runtime is built with CMake (see repository root):

```bash
cmake -B build -DCMAKE_BUILD_TYPE=Release -DNRR_BUILD_SHARED=ON
cmake --build build --config Release
```

Copy the produced library into the matching platform folder above. Unity only
deploys binaries that are inside `Plugins/` (optionally with an `.asmdef` and
platform settings via `.meta` files generated by the editor).

## ABI compatibility

- The library exports the C ABI declared in `include/nrr.h`.
- On Windows it must be built with `NRR_BUILDING_DLL` (the CMake shared target
  does this automatically) so `NRR_API` resolves to `__declspec(dllexport)`.
- The managed structs in `Runtime/Scripts/NRRTypes.cs` are layout-locked to
  the native structs; rebuild both together when the ABI changes.
